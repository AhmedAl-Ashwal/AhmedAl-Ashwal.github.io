# ahmedal-ashwal.github.io

Personal portfolio of **Ahmed Alashwal** — ERP Systems, Web & Mobile Applications Developer (Laravel · Flutter · Python), Sana'a, Yemen.

**Live:** [ahmedal-ashwal.github.io](https://ahmedal-ashwal.github.io)

## Features

- Bilingual **English / العربية** with full RTL support (toggle in the top bar, choice remembered)
- Design inspired by the *qamariyya* — the stained-glass fanlight windows of Old Sana'a
- Static HTML/CSS/JS — no build step, no frameworks; deploys on GitHub Pages and Vercel as-is
- Accessible: keyboard focus styles, reduced-motion support, semantic markup

## Structure

```
index.html            single page, English defaults + data-i18n keys
assets/css/style.css  design tokens & layout (CSS logical properties for RTL)
assets/js/main.js     EN/AR dictionary, language switching, scroll reveals
assets/images/        profile photo & favicon
```
